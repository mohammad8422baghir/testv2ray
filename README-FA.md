# آموزش بیلد APK با گیت‌هاب
۱) در github.com یک Repository جدید بساز (Private)، بدون README.
۲) Add file ← Upload files ← کل محتوای این پوشه (از جمله پوشه‌ی .github) را آپلود کن ← Commit.
۳) تب Actions ← workflow به نام Build APK ← Run workflow (یا خودکار بعد از Commit اجرا می‌شود).
۴) بعد از ۱۰ تا ۲۰ دقیقه، داخل run سبز، بخش Artifacts فایل my-vpn-apk را دانلود و unzip کن.
